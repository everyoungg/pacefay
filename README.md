# SAFE PAY — 소비자 중심 생체정보 보호 UX

다크패턴 없는 안전한 생체인증 가입 경험을 보여주는 발표용 프로토타입입니다.

## 실행
```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## Vercel 배포
1. GitHub에 이 프로젝트 업로드
2. Vercel에서 New Project → GitHub 저장소 선택
3. Framework Preset은 Next.js로 자동 인식
4. Deploy

※ 본 프로젝트의 Face Pay 화면은 발표용 가상 서비스이며 실제 토스 화면을 복제한 것이 아닙니다.
